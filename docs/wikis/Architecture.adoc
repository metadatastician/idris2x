= Architecture

Three pieces, only one of which is code:

[cols="1,2,3",options="header"]
|===
| Piece | What | Changes how often
| Launcher | Rust, one static binary, < 2,000 lines | Rarely (monthly engine train at most)
| Capsule factory | CI recipes driving upstream Makefiles in manylinux_2_28 containers and native macOS runners | Per upstream release
| Channel | One signed JSON document | Whenever data changes; a fix is a JSON diff plus `channel_version + 1`
|===

== Execution path

`resolve` (local, no network) → stat `store/sha256-<d>/.complete` (warm path) → otherwise fetch from mirrors with resume →
verify sha256 → safety-check the archive → unpack to staging → verify `sha256sums.txt` → run probes → atomic rename →
write `.complete` → compose the environment (a reset, ADR 0005) → `execve(<store>/bin/scheme, --program, idris2.so, args)`.

== Measured (Phase 0)

Cold install from a local mirror 3.3 s; warm no-op 1.7–2.8 ms (Go skeleton measurement, ADR 0007); capsule 35 MB gzip.
