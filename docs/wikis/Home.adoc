= idris2x wiki

*One command, exactly the Idris 2 compiler you pinned, or a loud error that tells you how to fix it.*

idris2x downloads an immutable, signed, self-testing Idris 2 + Chez Scheme *capsule*, verifies it, unpacks it
atomically into a content-addressed cache, and runs the real compiler. No system Chez, no `sudo`, works offline.

[NOTE]
====
*Planned (Phase 1).* The Rust launcher and published capsules do not exist yet. Commands on this page describe the
agreed interface (ADRs in `docs/decisions/`). The Linux prototype in `scripts/proto/idris2x.sh` implements the same
surface today for experiments.
====

== Five promises

. *No silent drift.* What runs is exactly the pinned digest, or nothing.
. *Atomic or absent.* An interrupted install leaves nothing half-done.
. *Loud by default.* Every failure has a stable ID, an exit code, a runbook and the exact fix.
. *The past never breaks.* A lockfile plus the capsule bytes is enough, forever, even if this project stops.
. *Verify before trust.* Signature, digest and canaries before the first run.
