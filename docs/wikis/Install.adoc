= Install

[NOTE]
====
*Planned (Phase 1).* The Rust launcher and published capsules do not exist yet. Commands on this page describe the
agreed interface (ADRs in `docs/decisions/`). The Linux prototype in `scripts/proto/idris2x.sh` implements the same
surface today for experiments.
====

idris2x is one static binary. Installing it never needs `sudo`, a compiler, Chez Scheme, Nix or mise.

== Methods (planned)

[cols="1,3",options="header"]
|===
| Method | Notes
| Release binary | Download from GitHub Releases for your platform and verify it before running it (below). Put it anywhere on `PATH`, e.g. `~/.local/bin`.
| mise / aqua registry | `mise use idris2x`: mise verifies the checksum and provenance for you.
| Homebrew, winget, Nix | Independently reviewed manifests pin the binary's hash; preferred where available.
| From source | `cargo install --locked --path .` in a clone (Rust ≥ 1.80).
|===

There is deliberately no `curl | sh` that fetches "latest": the first binary you trust should be pinned by a hash you can check.

== Verify the binary you downloaded

[source,bash]
----
sha256sum -c idris2x-<version>-<target>.sha256
gh attestation verify idris2x-<version>-<target> --repo metadatastician/idris2x
----

The root public key's fingerprint is published in the README and in each release's notes.

== Check it works

[source,bash]
----
idris2x doctor        # store writable, network or offline mode, platform, probes
----

== Where things go

[cols="1,2",options="header"]
|===
| What | Where
| Launcher binary | wherever you put it
| Capsules (content-addressed, immutable) | `$XDG_CACHE_HOME/idris2x/store/` (default `~/.cache/idris2x/store/`)
| Cached channel manifest, locks, staging | `~/.cache/idris2x/{manifests,locks,tmp}/`
| Your project's pins | `idris2x.toml`, `idris2x.lock` in the project
|===

Removing everything is just as explicit: see link:Uninstall[Uninstall].
