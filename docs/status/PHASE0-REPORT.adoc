== Verdicts on the plan's load-bearing assumptions

[cols="3,1,4",options="header"]
|===
| Plan assumption | Verdict | What is true (source)
| Idris 2 "0.8.1" is the current release | Refuted | Newest tag is v0.8.0 (2025-10-31). No binary assets upstream; capsules must be built from source.
| Pair Idris 2 with Chez 9.6.4 | Refuted | 9.6.4 exists but has no arm64 boot files and refuses Apple Silicon; Idris 2 needs threaded Chez and >= 10.0 on AArch64. Pin 10.4.1 (ADR 0004).
| Reuse upstream Chez release binaries | Refuted (Linux/macOS) | Upstream publishes only a Windows installer plus the source tarball. Build from tarball: 2 min 44 s on 4 cores, 6 MB installed.
| Relocation needs `CHEZSCHEMELIBDIRS` | Refuted | That variable only affects R6RS library import paths. Boot files use `SCHEMEHEAPDIRS`; Chez 10's compiled-in default is executable-relative, so a copied tree works with *no* variables.
| Idris 2 is relocatable via `IDRIS2_PREFIX` | Confirmed | Prefix baked in `src/IdrisPaths.idr`, overridden at runtime (`src/Idris/Driver.idr`). 11/12 canaries pass on a tree copied into a path with spaces.
| The `idris2` wrapper is relocatable | Partially | `bin/idris2` is sh; `bin/idris2_app/idris2.so` carries `#!<absolute chez path> --program`. Solved by direct exec (ADR 0005).
| glibc 2.28 floor | Partially | A build on ubuntu-24.04 needs `GLIBC_2.38`; the floor requires building inside manylinux_2_28 containers (ADR 0006).
| Go stdlib only + zstd + blake3 + TOML + minisign | Contradictory | Go 1.24 stdlib has no zstd, no blake2b/blake3, no TOML; minisign's default pre-hash is BLAKE2b. Resolved in ADR 0007/0008 (gzip or vendored decoder; sha256; signify-format Ed25519; JSON or TOML-subset lock).
| Bundle size 40–120 MB compressed | Confirmed (low end) | Linux x86_64 capsule: 137 MB unpacked; 35.4 MB gzip -9, 28.3 MB zstd -19, 19.5 MB xz -9 (before pruning ~30 MB of bootstrap `.ss`/`-boot.so` files).
| Warm path < 20 ms | Confirmed | Go skeleton: 1.7 ms no-op, 2.8 ms with lock parse + flock + execve (200-run loops). Bash prototype: ~40 ms.
| Launcher written in Go, repo scaffolded from rsr-template-repo | Refuted (Go) / Confirmed (template) | Estate LANGUAGE-POLICY §3 bans Go and Python for new work and the template's CI gates enforce it; `rust-cli` is the only CLI archetype; mint = `just repo-init rust-cli` (ADR 0011).
| Nothing already provides hermetic Idris 2 + Chez pairs | Confirmed | pack builds from source with BYO Chez; Homebrew bakes paths; no asdf/mise plugin, no setup action, no upstream binaries (PRIOR-ART.adoc).
| 12 canaries are implementable in ~10 lines each | Confirmed | All 12 written and run; `unicode_paths` fails because of an upstream Idris 2 bug (see UPSTREAM-NOTES.adoc), kept as expected-fail for 0.8.0.
|===

== What Phase 0 changed in the plan

. Pin `idris2@0.8.0` + `chez 10.4.1`; build both from pinned sources in CI (no upstream binaries exist).
. The launcher execs the capsule's Chez directly with an explicit environment contract; wrappers and shebangs are not trusted.
. Linux capsules come out of manylinux_2_28 containers; `min_glibc` is measured and recorded, and the launcher maps the dynamic-loader failure to `E-GLIBC-FLOOR`.
. Channel signatures are signify-format pure Ed25519; the manifest carries `expires`; both rollback and freeze are typed failures; execution never needs the manifest.
. Five error IDs added. Taxonomy and target matrix are TOML data with generators.
. One upstream bug report prepared (non-ASCII project paths, Chez backend).
. Language changed from Go to Rust to comply with the estate canon; generators rewritten without Python.
