= idris2x Roadmap

== Current Status

Phase 0 complete (2026-11-16): design pinned in ADRs 0004–0011 and tested on real builds (see PHASE0-REPORT.adoc).
Phase 1 in progress (2026-11-26): the Rust launcher is being built in four milestones. Milestone 1 (messages) is
merged; milestones 2 and 3 are open draft PRs. Milestone 4 has pin and channel trust built and tested with
`cargo test`; the chaos suite does not yet run against the Rust launcher, so it is not yet the CI gate.
Nothing is released, and no capsule is published.

== Milestones

=== Phase 0 — Spike (done)
* [x] Build Chez 10.4.1 and Idris 2 v0.8.0 from pinned sources; measure
* [x] Prove relocation (11 of 12 canaries on a relocated copy; one upstream bug)
* [x] Prototype launcher, factory and chaos suite (43 checks green at Phase 0; 121 after the DX design work, 2026-11-17)
* [x] Fact-check the plan against primary sources; record ADRs

=== Phase 1 — MVP (Rust launcher + factory)
* [ ] Rust launcher: resolve, fetch, verify, store, exec, doctor, selftest, gc, lockfile (< 2,000 lines of our own code; the cap was 1,000 until the owner raised it on 2026-11-26)
* [ ] Chaos suite as the launcher's CI gate
* [ ] Factory CI for idris2@0.8.0 × four Tier 1 targets (manylinux_2_28, native macOS), signed channel
* [ ] Error-message and DX design system applied to every output (parallel DX thread)
* [ ] Dogfood in estate proof lanes

=== Phase 2 — Trust layer
* [ ] Mirrors, hedged fetch, nightly canaries, churn drill, status page
* [ ] SLSA provenance, SBOM, immutable releases, two-tier keys
* [ ] Overlays, air-gap bundles, runbooks with triage notes

=== Phase 3 — Autonomy
* [ ] Bounded maintenance agent (human-only first month), Windows Tier 2, proofs per the proof plan

== Next actions

. Owner: apply rulesets, enable Discussions and immutable releases, create the wiki's first page, register at bestpractices.dev.
. Finish the Rust launcher: review and merge milestones 2 to 4.
. Port the chaos suite (`scripts/proto/chaos.sh`) to drive the Rust launcher, and run it in CI with a Chez Scheme
  built from source. Then add `cargo vendor` and `cargo deny` (ADR 0007).
