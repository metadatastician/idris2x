=== [Unreleased]

==== Added

* Minted from `hyperpolymath/rsr-template-repo` with the `rust-cli` archetype; deed identity filled (IS, IS-NOT, chain).
* Phase 0 results: ADRs 0004–0011, threat model, maintainers' abandonment contract, Phase 0 report with measured numbers,
  prior-art survey, estate-integration notes, upstream notes and the beyond-repo list.
* Error taxonomy (`src/errors/errors.toml`, 17 IDs), support matrix (`src/definitions/targets.toml`) and channel schema
  (`src/contracts/channel-v1.schema.json`), with generators for runbooks, the error-report issue form and wiki tables.
* Twelve canaries (`tests/canaries/`), the bash prototype launcher, capsule factory and 43-check chaos suite (`scripts/proto/`),
  and a std-only Rust fixture server (`examples/fixture_server.rs`).
* Issue forms (error report, capsule request, canary failure, DX feedback), project labels, PR checklist, agent rules
  for Copilot, CodeRabbit and Claude.
* Wiki source for users, platform maintainers, developers and theorists (`docs/wikis/`), published by `wiki-sync.yml`.
* Best-practice comparison (`docs/status/BEST-PRACTICES.adoc`).
* Rust launcher, milestone 1 (not released): the message module `src/msg.rs`, generated from `errors.toml` by
  `scripts/gen-errors-rs.sh`, renders every message byte for byte as the prototype does. It answers `explain`, `help`
  and `version` only. Context text is typed by provenance (ADR 0012).
* `E-OUTPUT` (exit 25): a failed write to standard output is a typed error, not a panic reported as `E-INTERNAL`.
* Eight error templates and one advice note no longer quote a lock or channel value in a sentence (ADR 0012); the
  value stays on its fact line. `[[advice]]` entries may carry `facts`.
* Rust launcher, milestone 2 (not released): `install`, `verify` and `fetch -o` read `idris2x.lock` with no network,
  download over https (or plain http to this machine only), resume a partial download, check the digest, unpack with
  the launcher's own containment checks, check the tree and run the two embedded probes, then rename into the store.
* `E-PIN-NOT-FOUND/unreadable-lock` (exit 10) and `E-USAGE/bad-setting` (exit 2): an unreadable lock and an unreadable
  setting are typed errors. The minimum Rust version is now 1.89, for file locks in the standard library.
* Review fixes for milestone 2: `E-GLIBC-FLOOR/unknown` (exit 16) refuses a glibc floor that `getconf` cannot check,
  instead of skipping it. `E-CAPSULE-INVALID/bad-metadata` (exit 21) refuses a `capsule.json` that does not describe
  the capsule. `E-STORE-IO/no-cache-dir` (exit 24) replaces a store in the current directory when `IDRIS2X_CACHE`,
  `XDG_CACHE_HOME` and `HOME` are all unset. A lock without schema 1 is refused. Settings that are not Unicode text
  are refused. Plain http is allowed only when the host itself is this machine (a user part is refused), and such a
  mirror may not redirect; an https mirror may redirect only to https. A hard link that cannot be written is a disk
  failure, not an unsafe archive. `getconf` runs with `PATH` only.
* The launcher line cap is 2,000 lines of our own code, raised from 1,000 by the owner on 2026-11-26. Milestone 2
  has 1,326 lines with its review fixes; all of Phase 1 is projected at about 1,700 to 1,800.
